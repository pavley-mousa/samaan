# مزامنة Samaan تلقائيًا داخل VS Code على Windows

تمت إضافة مهمة VS Code باسم **Samaan: Auto-sync GitHub** مع سكربت PowerShell آمن.

## تشغيلها لأول مرة

1. افتح مجلد المستودع بالكامل `samaan` في VS Code — وليس مجلد `apps/storefront` وحده.
2. افتح Terminal داخل المجلد ونفّذ مرة واحدة:
   ```powershell
   git pull --ff-only origin main
   ```
   نفّذ ذلك فقط بعد التأكد أن التعديلات المحلية محفوظة أو ملتزم بها (committed/stashed).
3. عندما يسألك VS Code عن السماح للمهام التلقائية، راجع المهمة واختر **Allow**. ويمكن إدارتها لاحقًا من Command Palette بالأمر **Tasks: Manage Automatic Tasks**.
4. افتح المجلد مجددًا. ستبدأ مهمة **Samaan: Auto-sync GitHub** وتفحص الفرع `main` كل 60 ثانية.

## قواعد الأمان

- تُطبَّق التحديثات تلقائيًا فقط عندما تكون على الفرع `main` ولا توجد تعديلات محلية أو ملفات غير متتبعة.
- يستخدم السكربت `git fetch` و`git merge --ff-only`؛ لا يمسح تعديلاتك ولا ينفذ merge متعارضًا.
- لو وجدت تعديلات محلية غير محفوظة، ستتخطى المزامنة إلى أن تحفظها أو تعمل لها commit/stash.
- يلزم اتصال إنترنت ومصادقة GitHub صالحة. سيظل التحديث محليًا إلى أن تكون نسخة الفرع المحلي قادرة على التقدم بأمان.
- أي مجلد غير مستنسخ باستخدام Git لا يستطيع استخدام المزامنة هذه؛ استنسخ المستودع من GitHub أولًا وافتح مجلده الجذر.

## ملاحظة

المزامنة تحدث ملفات المشروع داخل VS Code. Next.js يحدّث التغييرات عادةً تلقائيًا إذا كان خادم التطوير قيد التشغيل. لا تقوم المهمة بنشر الموقع على Vercel؛ النشر منفصل.
